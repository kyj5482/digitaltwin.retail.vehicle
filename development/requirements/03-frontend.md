# 03. Frontend 요구사항 — v10 수준

v10 프로토타입의 상호작용 문법이 사양(spec)이다. 실개발 프런트는 아래 구성요소·기술 요건을
법인 프로필(entity-config) 주입 위에서 동일하게 제공해야 한다.

## 씬 문법 (대시보드가 아니라 트윈)

- **관계뷰 메인 씬** — 법인(루트) 아래 목표 영역·KPI·부문이 하나의 관계망. 클릭으로
  업스트림/다운스트림을 오르내리는 중첩 드릴 (차트 나열 금지).
- **파티클 플로우** — 데이터·실행의 흐름을 씬 위 파티클로 상시 표현.
- **폐루프** — 부문 실행 → 온톨로지 원장 → KPI 롤업의 리턴 채널이 씬에 보인다.
- **Play 타임라인** — 월 커서로 과거 실적을 재생하고 NOW 이후는 시뮬레이션 예측으로 구분.
- **BP 대비** — 모든 KPI 값은 BP 목표 대비로 읽힌다 (달성률·편차).
- **전략 레버** — 도메인 월드에서 레버 조작 → 미래 재생성 → 적용 시 트윈 월드 KPI로 환류.

## 화면 구성요소 (v10 레이아웃 승계)

| 영역 | 구성요소 |
|---|---|
| 헤더 | 단일 제목줄 + 브레드크럼(열린 월드 스택) + 뒤로가기 — 제목줄은 레지스트리에서만 파생 |
| 좌 레일 | 회사 목표 가중 달성률 · Quick Link(관계뷰 바로가기, 사용자 저장) · AI 에이전트 위임 현황 |
| 중앙 | 관계뷰 씬 (SVG) + 포커스 그래프 패널 |
| 우 레일 | 포커스 정보 · 기여 프로젝트 (온톨로지 Top-down 컴포저) |
| 푸터 | Play · 월 표시 · 타임라인 슬라이더 |
| 오버레이 | 부문 운영 월드 (탭·스텝 레일·씬·트렌드 밴드·실행 피드) · 소환 월드 · 인트로 |

## 기술 요건

1. **설정 주입** — 법인 고유 값은 `entity-config.js`(빌드 생성물)로만 주입.
   생성물이 없으면 기본값으로 동작 (프로토타입과 동일한 폴백 규칙).
2. **무플래시 전환** — 01 문서의 라우팅 규격 준수. 상태 선적용 후 첫 페인트,
   전환 중 베일/스켈레톤, 이전 제목줄 노출 금지.
3. **디자인 토큰** — 다크 기반 `--` 토큰 팔레트 단일 소스. canvas·지도 등 CSS var를
   못 쓰는 렌더러도 `:root`에서 조회 (프로토타입 `CV()` 패턴).
4. **경로 규칙** — 모든 리소스·API는 상대 경로 (CloudFront 프리픽스 배포 호환,
   `server.js` 프리픽스 모드로 로컬 검증).
5. **임베드 모드** — 온톨로지 관계뷰는 `?embed=1`로 크롬 없이 소환 가능해야 한다.
6. **성능** — L0 첫 페인트에 L3 인스턴스 로드 금지 (레벨별 지연 로드) ·
   씬 애니메이션은 rAF 단일 루프 · 컨테이너 리사이즈에 씬 재-fit.
7. **상태 보존** — Quick Link 등 사용자 상태는 로컬 저장(프로토타입 localStorage)에서
   실개발 시 사용자 프로필 저장소로 승격.
