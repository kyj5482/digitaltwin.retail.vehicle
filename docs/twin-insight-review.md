# 판매법인 관점 트윈 인사이트 리뷰 — V6 기준 (2026-08)

> 질문: "실제 법인 입장에서 현재 트윈이 인사이트를 얻기 좋은가?"
> 평가 방법: 판매법인 실무자가 매월/매주 실제로 던지는 질문 목록에 대해,
> 현재 V6가 몇 클릭 안에 답을 주는지 / 답을 못 주는지로 판정한다.

---

## 1. 현재 잘 되는 것 (유지·강화)

| 실무 질문 | 현재 V6의 답 |
|---|---|
| 지금 재고가 어디에 얼마나 있나? (공장·운송·지역) | ✅ 지도 + 차량 아이콘 스택 + 줌인 상세로 즉답 |
| 특정 차종의 공급 흐름은? (예: Lumen EV) | ✅ 차종 필터 → 국내 1공장→수출항→수입항→지역 회랑만 표시 |
| 이 회랑의 운송은 얼마나 걸리나? | ✅ 경로 배지 "대수/월 · ⏱ N일" + 구간 분해 툴팁 |
| 이 집계 숫자의 근거는? | ✅ 집계 → VIN 샘플 → 이벤트 체인 3단 드릴 |
| 조직 구조상 어디 소속의 문제인가? | ✅ 권역본부 → 산하법인 → 지역 계층 내비게이션 |
| 과거 특정 월의 상황 재현 | ✅ 타임라인 재생 |

**결론: "지금 무슨 일이 일어나고 있는가(What)"의 가시성은 확보됨.**

## 2. 인사이트 갭 — 실무 질문인데 현재 답 못하는 것

인사이트는 "상태를 보는 것"이 아니라 **"판단 → 행동"으로 이어지는 것**이다.
현재 트윈은 상태 재현(디스크립티브)까지 왔고, 아래 5개 갭이 판단·행동 단계를 막고 있다.

### 갭 ① 기준선 부재 — "그래서 좋은 건가 나쁜 건가?"
- 운송 32일, West 재고 4,200대라는 숫자를 봐도 **목표/정상 범위 대비 판단 신호가 없다.**
- 실무자는 절대값이 아니라 델타(vs BP, vs 목표 DS 60일, vs 전월/전년, vs 표준 리드타임)로 판단한다.
- → **업그레이드 A: 비교 오버레이 모드** — 뷰 전환 토글 [현재값 | vs 목표 | vs 전월 | vs BP].
  델타 모드에서는 카드·경로가 다이버징 색(초과=적, 미달=청)과 증감 화살표로 바뀐다.

### 갭 ② 발견의 자동화 부재 — 병목을 사람이 눈으로 찾아야 한다
- 지금은 사용자가 줌인·필터를 조작하며 이상을 **스스로 찾아야** 한다. 지역 5×차종 6×공장 5의 조합을 눈으로 훑는 것은 트윈 이전 방식과 동일한 노동이다.
- → **업그레이드 B: 인사이트 모드(경보 자동 하이라이트)** — 매월 규칙 엔진이 씬을 스캔해
  이상 지점만 배지로 띄운다: 재고 과잉/부족 지역, 표준 초과 회랑(리드타임 +N일), 케파 초과 공장,
  판매속도 급변 차종. 배지 클릭 → 해당 위치로 줌 + 근거 패널. "이번 달 주목할 N가지"가 첫 화면이 되는 것.

### 갭 ③ 수요 측 단절 — 공급 트윈에 머물러 있다
- 현재 흐름은 공장→딜러의 **공급 밀어내기**만 보인다. 판매법인의 본질 질문은
  "수요와 공급이 만나는 지점이 건강한가"다: 지역별 판매 속도 vs 재고(회전), 인센티브 투입 대비 반응,
  마케팅 → 딜러 방문 → 판매 퍼널, 트림/색상 미스매치(잘 팔리는 사양이 없는 지역).
- → **업그레이드 C: 수요 레이어** — 지역 플레이트에 판매속도/회전일 게이지, 차종×지역 미스매치 지표
  (재고 Mix − 판매 Mix 괴리), 인센티브·마케팅 투입 오버레이.

### 갭 ④ 품질·서비스 루프 미가시화
- 피드백 데이터 스트림은 "선"으로는 있지만 **내용물이 안 보인다**: 지역별 VoC 급증, 캠페인 대상
  UIO 규모, 서비스 베이 포화 → CSI 하락으로 이어지는 인과 체인이 씬에 없다.
- → **업그레이드 D: 품질 레이어** — 지역별 VoC/천대 히트, 캠페인 발생 시 대상 UIO·서비스 부하·
  예약 지연일이 씬 위에 표시되고, 부하 초과 지역이 경보로 뜬다 (갭 ②의 규칙에 편입).

### 갭 ⑤ 행동 연결 부재 — 보고 끝난다
- 이상을 발견해도 트윈 안에서 **"그러면 이렇게 하면?"을 실험할 수 없다.** V3 콕핏에 시나리오 엔진이
  있지만 V6 씬과 분리되어 있다.
- → **업그레이드 E: 씬 위 what-if** — V3의 시나리오 엔진을 V6에 접목. 지역/공장/회랑에서 바로
  조정(배분 ±%, 주문량, 인센티브)하면 미래 구간의 흐름·재고 스택이 재계산되어 씬에서 미리 보인다.
  결과가 좋으면 "Action Item으로 저장" → 월 주문 프로세스로 연결.

### 부가 갭 (차순위)
- **재무 부재**: 경로별 운송비, 지역·차종별 마진이 흐름에 없다 → 재무 오버레이는 갭 ①·⑤와 함께.
- **미래 구간 신뢰도**: 시뮬레이션 월의 씬이 실적과 같은 강도로 그려짐 → 신뢰 밴드/투명도 차등 필요.
- **비교의 부재(시나리오 간)**: 시나리오 A/B가 씬에서 나란히 비교되지 않음 (V3에는 있음).

## 3. 업그레이드 로드맵 제안

| 단계 | 내용 | 갭 | 판단 기준 |
|---|---|---|---|
| **1단계** | 비교 오버레이(vs 목표/BP/전월) + 인사이트 모드(경보 자동 하이라이트) | ①② | 트윈을 열면 "이번 달 주목할 것"이 3클릭 이내에 나오는가 |
| **2단계** | 수요 레이어(판매속도·미스매치) + 품질 레이어(VoC·서비스 부하) | ③④ | 지역 하나를 보면 수요·공급·품질이 한 화면에서 판단되는가 |
| **3단계** | 씬 위 what-if (V3 엔진 접목) + Action Item 저장 | ⑤ | 발견→실험→액션이 트윈 안에서 완결되는가 |
| **4단계** | AI 에이전트 월간 브리핑 (경보 요약 + 원인 추정 + 권고안 자동 생성) | 자동화 | 사람은 승인·예외만 다루는가 |

- 1단계가 투자 대비 효과가 가장 크다: 이미 있는 데이터(BP, 목표 DS, 전월)와 씬 위에
  **비교·경보 표현만 추가**하면 되고, "보는 도구"가 "판단하는 도구"로 바뀐다.
- 3단계부터는 프로토타입(가상 데이터)보다 실데이터 P1~P2와 병행하는 것이 효율적이다.

## 4. 총평

현재 V6는 **공급망 상태의 재현(디지털 트윈의 몸)**은 갖췄다. 다음 단계는 **판단 기준과 경보(신경),
수요·품질까지의 폐루프(감각), 씬 위 시뮬레이션(사고)**을 얹는 것이다. 이 순서(1→4단계)로 가면
"업무를 비추는 거울"에서 "전략을 실험하는 장치"로 넘어가며, 그것이 원래 과제 목표
(트레이드오프 시뮬레이션 → Action Item 사전 도출)와 정확히 맞물린다.
