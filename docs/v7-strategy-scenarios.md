# V7 — CEO 전략 시뮬레이션 트윈: 시나리오 정의서

> V6까지가 "무슨 일이 일어나고 있는가"(상태 재현)였다면, V7은 **"이 전략을 쓰면 무슨 일이 일어날 것인가"**(전략 시뮬레이션)를 답한다. CEO가 전략 레버를 움직이면 동일한 State 위에서 다른 미래가 생성되고, BP 대비 KPI 궤적 차이가 씬과 차트에서 동시에 보인다.

| # | 시나리오 | 레버 세팅 | 작동 메커니즘 (모델 체인) | 예상 트레이드오프 (관전 포인트) |
|---|---|---|---|---|

| S2 | **인센티브 +$800 판촉** | 인센티브 +$800 | 실거래가↓ → 수요 +3~4% → 재고 소진·DS↓ | 판매↑ vs 대당 $800 비용. 인센티브 $2,200 초과 시 브랜드 손상 → CSI 하락 시작 |

## 3. 시뮬레이션 모델 스펙 (Model Layer)

실적 데이터 생성기(`data/_generator/generate.py`)와 **동일한 구조식**을 사용한다 — 과거를 만든 모델이 미래를 생성하므로 캘리브레이션이 정의상 성립.

```
수요[m,차종] = 기저수요 × 계절지수 × 인센티브효과 × MSRP효과 × 침식효과 × 마케팅효과
  인센티브효과 = ((MSRP − 인센티브) / (MSRP − 1200))^(−1.6)      ← 실거래가 경로, 브랜드 레벨
  MSRP효과    = (1 + 가격레버)^(−4.0)                            ← 경쟁 대비 상대가격, 모델 레벨(BLP)
  침식효과    = max(0.3, 1 − 0.003 × 가격레버% × 경과월)          ← 지속 인상 시 브랜드 고려도 침식
  마케팅효과  = clamp(1 + 0.10·log₂(adstock/기준), 0.85, 1.25),  adstock = 당월 + 0.5·전월
소매 = min(수요 × (0.75 + 0.25·가용성), 재고×0.95),  가용성 = min(1, 재고/(수요×0.9))
도매 = 수요 + (목표재고 − 재고)×0.5  (목표 DS 레버 반영),  차종 전담 라인 케파 상한
  EV 램프업 실효 케파(미래 시뮬 가정): 사바나 5,300 · 국내1공장 9,000대/월 → 증산 레버로 확대
영업이익 = 도매×(대당마진 + MSRP×가격레버) − 소매×인센티브 − 도매×운송비 − 품질비 − 마케팅비
CSI = 88.5 − 0.0008·max(0, 인센티브−2200) − 0.02·max(0, DS−80) − 0.05·max(0, 40−DS), 관성 0.8
불확실성 밴드 = ±(3% + 0.6%×경과월)  (호라이즌이 멀수록 넓어지는 팬차트)
```

### 파라미터 근거 (문헌)
- **가격탄력성 2티어**: 자동차 시장 전체 −0.9 (McCarthy 1996), 개별 모델 −3~−6 (BLP 1995, NBER w4264). 인센티브(한시적·타깃형)는 브랜드 레벨 **−1.6**, MSRP 인상(경쟁사는 유지 → 대체효과 발생)은 모델 레벨 **−4.0**을 적용. 지속 인상 침식항은 튜너블 가정(−0.3%p/월/%).
- **인센티브 전가율**: 고객 리베이트 70–90%, 딜러 캐시 30–40% (Busse et al. 2006, AER). 본 모델은 고객 리베이트 가정(100% 실거래가 반영)으로 단순화.
- **adstock 이월 0.5**: 광고 반감기 2–5주 → 월 단위 0.3–0.5 (Broadbent adstock). 광고탄력성 단기 0.12·장기 0.24, 내구재는 상단 (Sethuraman et al. 2011, JMR).
- **재고→판매 전환**: DS 45일 미만이면 트림·색상 미스매치로 판매 기회 손실, 75일 초과는 효과 없음+노후화 할인 압박 (Cachon et al. 2019 Mgmt Sci; Cox Automotive DS 기준).
- **리드타임** (KR 2개월 / MX 1개월 / US 0개월): 업계 표준 가정치 — 튜너블 상수로 노출.

## 4.5 시나리오 관리와 상세 분석 (2차 기능)

- **시나리오 레지스트리**: 레버 조합을 이름 붙여 등록하면 시나리오 목록에 쌓이고, 표시 토글된 것은 **모두** KPI 차트에 색상별 파선으로 오버레이된다. 행별 [표시 토글 · 적용(레버 불러오기) · 삭제]. 프리셋 카드 S1~S5는 레버 빠른 세팅용이며 등록을 거쳐야 목록에 남는다.
- **상세 분석 모드**: 왼쪽 KPI 레일이 유지되며 **타일 클릭으로 분석 그래프 지표 전환**(판매량/영업이익/DS/CSI — 영업이익·재고는 사양 믹스 비례 배분 근사, CSI는 사양 필터 미적용 존별 근사). 그래프 x축은 메인과 동일한 48개월 시계열이고 **하단 타임라인 Play와 커서가 연동**된다. 차종·MY·트림·엔진·구동(AWD/FWD)·색상을 **카테고리별 다중 선택**으로 필터링해 지역별 트렌드와 "최근 3개월 vs 이전 12개월" 변화율을 비교한다. 우측의 변화율 바와 **자동 탐지 TOP 6는 현재 필터를 기준으로 즉시 재계산**되며(제목에 필터 요약 표시), 탐지 행 클릭 시 해당 사양이 필터에 반영된다. 데이터 원천은 `data/retail_sales_attr`(MY·엔진·구동)·`data/retail_color_mix`(색상), 데모용 정답 이상 징후 2건(A1: Vista FWD South/Southeast 급락, A2: EV 화이트→그레이 West/Northeast 이동) 주입.
- **차트 상호작용 (메인·분석 공통)**: 휠=Y축 줌(커서 값 중심), 세로 드래그=Y축 이동(팬), 호버=월·시리즈별 값 툴팁, 상단 [Y축 초기화 ↺] 버튼으로 복원. 메인 차트는 클릭 시 해당 월로 이동.
- **KPI 크로스 필터링**: 상세 분석 필터가 활성이면 왼쪽 KPI 타일·스파크라인도 슬라이스 값으로 전환된다(필터 배너 표시, 닫으면 전사 복귀). 원칙: ① 손익은 VIN 단위로 계산되므로 사양 필터는 근사가 아니라 **정확한 집계** — 마진 항은 트림 가격계수 정밀 배분(`financials_pnl_attr`, 합계=모델 손익), ② CSI 서베이는 VIN 연계라 차종 필터가 정확히 반영(캠페인 딥은 해당 차종 오너에 집중 — AUR 필터 시 CSI 69대까지 하락), ③ **BP는 믹스 모델로 사양 레벨까지 상향식 생성**(`bp_target_attr`, 계획 시점=이상 징후 미반영 믹스)이므로 어떤 필터 조합에도 "vs BP"가 성립. 필터 차원 추가 시 생성기만 확장하면 실적·BP·화면 전체 downstream이 자동 반영 (SCHEMA.md §8).
