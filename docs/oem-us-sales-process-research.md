# 미국 자동차 판매법인 업무 프로세스 리서치 — 8사 비교

> 목적: V8(전략 시뮬레이션)·V9(라이프사이클)를 **하나의 디지털 트윈 월드(V10)**로 통합하기 위한
> 도메인 입력. 포드·GM·도요타·혼다·스바루·테슬라·현대·기아의 미국 판매법인(NSC/직판)이
> 실제로 돌리는 프로세스를 공개 정보·업계 통설 수준에서 정리하고, 현재 트윈이 커버하는 범위와
> 갭을 도출한다. 세부 수치·시스템명은 프로토타입 설계용 참고이며 사실 확인이 필요한 항목은 (추정) 표기.

## 0. 공통 프레임 — 미국 판매법인(NSC)의 두 가지 유통 모델

| 모델 | 해당사 | 핵심 구조 |
|---|---|---|
| **프랜차이즈 딜러 모델** | 포드·GM·도요타·혼다·스바루·현대·기아 | 법인이 딜러에 **도매(Wholesale)** → 딜러가 소매. 재고 리스크는 딜러(플로어플랜 금융), 법인은 도매 시점에 매출 인식. 주(州) 프랜차이즈법이 직판 금지 |
| **직판(Direct) 모델** | 테슬라 | 법인이 소비자에 직접 판매. 주문(Config)-생산-인도 일치, 재고 최소, 가격 실시간 조정 가능 |

프랜차이즈 모델의 연간 사이클(공통 골격)은 현재 V9가 트윈한 것과 동일하다:
**상품 확정(MY) → 볼륨·트림믹스 사업계획 → FOB/Invoice 가격 → 마케팅(Tier 1/2/3) →
월 생산 주문·배분(Allocation) → 도매 → 소매·인센티브 → VoC·품질(TSB/리콜/OTA) → 서비스·파츠 → 차기 상품 반영.**

차이는 "누가 주문 수량을 결정하는가(법인 배분 vs 딜러 주문 vs 고객 주문)"와
"품질 루프의 속도(딜러 정비 기반 vs OTA 기반)"에서 갈린다.

## 1. 각사 프로세스 요약

### 1.1 Ford Motor Company (직영 판매 조직 — NSC 아님, 본사 직속 US Sales)
- **주문**: 딜러가 **오더 뱅크**에 주문 입력 → 본사가 생산 제약·부품 수급 기준으로 스케줄 인(스핀). 리테일 오더(고객 주문)와 스톡 오더 구분, 리테일 오더 우선 스케줄
- **배분**: 세그먼트별 판매 실적 + 재고 회전 기반 얼로케이션. COVID 이후 "오더 기반(build-to-order) 비중 확대" 전략을 공식화했다가 재고 판매로 일부 회귀
- **마케팅**: Tier 1(전국 브랜드) / Tier 2(딜러광고협회 FDAF) / Tier 3(개별 딜러) 3층. 프라이빗 오퍼(타겟 인센티브) 활용
- **품질**: TSB + 리콜(FSA: Field Service Action) + **Power-Up OTA**(F-150/Mustang Mach-E 등). Ford Pro(상용)는 텔레매틱스 기반 선제 정비
- **파츠**: Motorcraft/Ford Parts 이원 브랜드, 딜러넷 가격 + 워런티 정산 단가 별도 관리

### 1.2 General Motors
- **주문·배분**: 전통적 **Turn-and-Earn**(판 만큼 배분 받는다) — 딜러 소매 실적이 차기 배분권을 결정. 제약 차종은 별도 컨스트레인트 관리
- **계획**: 오더 가이드(Order Guide)로 MY 사양·옵션 확정 → 딜러 주문 → 컨센서스 물량 조정
- **마케팅**: 브랜드(쉐보레·GMC·뷰익·캐딜락)별 전국 캠페인 + LMA(지역 마케팅 협회)
- **품질**: OnStar 텔레매틱스 데이터 기반 조기 감지, TSB/리콜, 일부 OTA(얼티엄 EV)
- **특징**: 캡티브 금융(GM Financial)의 플로어플랜·리스 잔가가 판매 프로그램과 강결합

### 1.3 Toyota Motor North America (TMNA)
- **유통 특수성**: 대부분 직영 리전이지만 **Southeast Toyota(JM Family)·Gulf States Toyota** 두 개의 **독립 디스트리뷰터**가 존재 — 법인→디스트리뷰터→딜러 3단계 구간이 있음
- **주문·배분**: 리전별 **턴 레이트(회전율) 기반 배분**. 딜러는 배분 물량의 사양을 제한된 범위에서 스왑/조정. 재고를 얇게 유지(도요타식 저 DoS 운영)
- **계획**: 호신(方針) 전개식 연간 계획 — 전사 목표를 리전·차종으로 캐스케이드
- **품질**: 딜러 정비 데이터 + SMART(초기 품질 조기 경보) → TSB/리콜. 안전 이슈는 별도 위원회 의사결정(HITL 성격 강함)
- **파츠**: 딜러 일일 발주 + 리전 PDC(부품센터) 네트워크, 순정부품 가격 체계 엄격

### 1.4 American Honda Motor (AHM)
- **주문**: 트림 수를 적게 유지(모노 스펙에 가까움) → 믹스 결정이 단순, 공장-딜러 리드타임 짧게 운영
- **배분**: 판매 실적 기반 + 딜러 재고 상한 관리. 역사적으로 인센티브 절제(브랜드 잔가 방어) — 프로그램 설계가 보수적
- **마케팅**: 전국 + 딜러광고협회. 신차 런칭 시 Feature 중심 캠페인(예: 센싱, 하이브리드)
- **품질**: iN(딜러 포털) 기반 TSB 배포, 캠페인 VIN 추출 자동화
- **특징**: 트림 단순화 덕분에 "지역×색상" 레벨 재고 밸런싱이 상대적으로 중요 — V9의 DoS Weight 주문 로직과 가장 유사한 형태

### 1.5 Subaru of America (SOA)
- **유통 특수성**: **Subaru of New England**가 여전히 독립 디스트리뷰터
- **주문**: 딜러 주문 + 저재고 운영(수요 초과가 상시) — 사실상 배분제. DoS가 업계 최저 수준
- **마케팅**: "Love Promise" 장기 브랜드 캠페인 + 리테일러 이벤트(Share the Love). 퍼포먼스보다 브랜드 자산 중심
- **품질·CSI**: 소규모 라인업이라 차종별 품질 이슈가 브랜드 전체 CSI에 직결 — CSI 모니터링·회복 활동이 경영 어젠다
- **파츠**: Added Security(연장보증)와 서비스 리텐션 프로그램이 파츠 수익의 축

### 1.6 Tesla (직판 — 대조군)
- **주문**: 고객 Config 주문 → 생산 슬롯 배정 → 인도. 트림믹스·배분·도매 개념이 없음
- **가격**: 수요에 따라 실시간 가격 조정(사실상 상시 레버 실행) — V8 가격 레버의 극단형
- **품질**: **OTA-first** — 이슈 감지(텔레메트리) → SW 수정 배포 → 리콜의 상당수를 OTA로 종결. V9의 QLT→OTA 폐루프가 가장 빠르게 도는 사례
- **서비스**: 직영 서비스센터 + 모바일 서비스. 파츠 가격의 딜러넷/팩토리 균형 문제가 없음(내부 이전가만 존재)
- **시사점**: 직판 모델은 "라이프사이클 단계 수가 줄고 루프 속도가 빨라진다" — 트윈 월드에서 **루프 속도(리드타임)를 1급 지표**로 다뤄야 하는 근거

### 1.7 Hyundai Motor America (HMA)
- **주문**: 본사(생산법인)와 월 단위 생산 주문 — **과거 소매 실적 + 재고 일수(DoS) 기반 배분**, 지역(리전)×트림×색상 레벨로 주문 (V9 ORD-1의 직접 모델)
- **계획**: 연간 사업계획(BP)을 도매 기준으로 수립, 트림믹스·FOB를 본사와 협의 확정 — V9 BP-1/2/3의 직접 모델
- **마케팅**: 전국 캠페인 + 리전 협회, 신기술 Feature(캘리그래피, HTRAC 등) 중심 매체 제작
- **품질**: 캠페인/리콜 + **Bluelink OTA** 확대. 세타 엔진 사태 이후 품질 데이터 파이프라인·조기 경보 투자 강화
- **파츠**: 순정부품(Mobis 공급) 딜러넷 가격과 워런티 정산 단가의 균형 관리 — V9 SVC-1의 직접 모델

### 1.8 Kia America
- HMA와 구조 동형(같은 그룹). 딜러 수·리전 구성이 다르고, 인센티브·플릿 비중 운영이 별도
- 텔레매틱스 Kia Connect, EV 라인업 확대에 따른 OTA 조치 증가
- 딜러 재고 목표(DS 밴드)를 리전별로 관리하며 월 주문에 반영

## 2. 공통 라이프사이클 종합 — V9 캘린더 15개 활동 매핑

| 단계 | 8사 공통 실무 | V9 반영 | 갭 |
|---|---|---|---|
| 상품 준비 | MY 사양 확정, 오더 가이드 발행 | PP-1/PP-2 (게이트 G1~G4) | 오더 가이드=딜러 공지 단계 없음(경미) |
| 사업계획 | 도매 기준 볼륨·믹스 계획, 본사 협의 | BP-1/2/3 (FOB 확정) | **승인 게이트(HITL) 미표현** |
| 마케팅 | Tier 1/2/3, Feature 캠페인 | MKT-1/2/3 | Tier 2/3(딜러 협회) 미표현(P2) |
| 주문·배분 | Turn-and-Earn·턴레이트·DoS Weight | ORD-1 (수식 내장) | **딜러 수용/컨센서스 단계 미표현** |
| 판매 | 도매→소매, 월 인센티브 프로그램 | SLS-1/2 + V8 레버 | 프로그램 설계→발표 월 주기 미표현(경미) |
| 품질 | VoC·텔레메트리→TSB/리콜/OTA | QLT-1/2 | **리콜 의사결정 게이트(안전, HITL 필수) 미표현** |
| 서비스·파츠 | 딜러넷/워런티 단가 균형, 리텐션 | SVC-1/2 | 캡티브 금융·연장보증 미표현(P2) |

## 3. V10 디지털 트윈 월드 갭 백로그

**P0 — 이번 V10에서 구현 (모든 회사에 공통이며 "실제 업무가 월드에서 수행"의 핵심)**
1. **워크플로우 게이트 + Human-in-the-loop**: BP 승인, FOB 확정, 리콜/캠페인 결정, 가격 개정 등은 사람이 검토·승인하는 게이트. 나머지(VoC 분류, 주문 배분 초안, 매체 예산 배분, 캠페인 VIN 추출)는 **AI 에이전트 위임** 가능 — 게이트마다 [자동실행→검토대기→승인/반려] 수명주기
2. **목표 Breakdown(Goal Tree)**: 판매량·영업이익·고객만족도 3대 목표를 KPI 트리로 분해, 각 노드가 데이터(agg_kpi·csi)와 1:1 바인딩 — 레거시처럼 부서별 프로세스가 따로 돌지 않고 하나의 Goal로 정렬
3. **프로젝트 컴포저(온톨로지 Top-down)**: 새 프로젝트를 목표 노드 아래에 추가하면 온톨로지에서 연계 객체(차종·지역·딜러·캠페인·조치)가 자동 연결되고, 기대 임팩트(V8 시뮬레이션 수식)와 실적 리뷰가 쌓임
4. **시나리오→실행 연결**: V8 시나리오 커밋 결과가 V9 다음 달 주문(ORD-1)·CSI 개선 활동으로 흘러가는 폐루프

**P1 — 후속**: 딜러 수용/컨센서스 단계(주문 협상), 인센티브 프로그램 월 주기, 루프 리드타임 지표(테슬라 대조)
**P2 — 장기**: Tier 2/3 마케팅, 캡티브 금융·플로어플랜, 플릿/CPO, 독립 디스트리뷰터 구간(도요타·스바루)
