# CEO 1-DAU 리뷰 — "미국 시장 CEO가 이 트윈을 매일 여는가?" (V7 기준, 2026-08)

> 질문: 포드·GM·도요타·기아·현대 (미국 시장) CEO 입장에서 V7을 **하루 1회 이상** 접속할 것인가?
> 기준: CEO는 단 한 명이므로 DAU=1은 "매일 아침 이 화면이 그의 결정을 바꾸는가"와 동치다.
> 선행 조사: `twin-insight-review.md`(V6 5대 갭), `v7-strategy-scenarios.md`(레버·모델 근거).

---

## 1. 평가 프레임 — CEO가 무언가를 "매일" 여는 조건

소비자 앱의 DAU 공식(매일 새로움 · 개인화 · 손실 회피)은 CEO에게도 그대로 적용된다.

1. **매일 갱신되는 사실 중 내 결정을 바꾸는 것이 있는가** — 어제와 오늘이 다른가
2. **남보다 먼저 아는가** — 보고 라인이 올리기 전에 위험을 포착하는가 (손실 회피)
3. **회의를 소집할 근거가 되는가** — "이 화면 보고 모여" 한 마디로 어젠다가 서는가
4. **어제 내가 시킨 것이 추적되는가** — 결정→실행→실적의 스코어보드

## 2. 페르소나별 판정 (5사 CEO 아키타입)

실존 인물 스타일을 아키타입화한 것이며, 공통 조직 맥락(미국 판매법인 CEO)을 가정한다.

| 아키타입 | 아침의 첫 질문 | V7 현재 답변력 | 매일 접속? |
|---|---|---|---|
| **포드형** (딜러·프라이싱 실무형 — 인센티브 $/대까지 직접 봄) | "어제 소매 몇 대? 인센티브 소진율은? 딜러 재고 어디가 썩고 있나?" | 레버·DS 워터폴·지역 포커스 ✅ / **일 단위 데이터 ✗, 딜러 단위 ✗, 경쟁 인센티브 ✗** | △ 주 2~3회 |
| **GM형** (포트폴리오·케파 배분형 — EV 전환 자본배분 중심) | "사바나 램프업 계획대로인가? EV/ICE 믹스 배분 바꿔야 하나?" | 케파 병목 점멸·EV 증산 레버·믹스 필터 ✅ / 자본·CAPEX 관점 ✗ | △ 주 1~2회 |
| **도요타형** (오퍼레이션 규율형 — 회전·품질 이상 조기 감지) | "DS 표준 이탈 지역은? 품질 신호 이상 없나?" | DS 흐름 분해·CSI 요인 워터폴·개선활동 원장 ✅ / **일 단위 이상 감지 ✗** | △ 주 1~2회 |
| **기아·현대형** (점유율 성장형 — 세그먼트 쉐어·인센티브 효율) | "세그먼트 점유율 방어되나? 인센티브 1$당 몇 대를 사는가?" | 판매·손익 브리지, 인센 탄력성 모델 ✅ / **경쟁·SAAR·점유율 데이터 자체가 없음** — 최대 갭 | ✗ 월 단위 |

**공통 판정: V7은 "주간 전략 검토 도구"로는 합격, "매일 아침 도구"로는 미달.** 이유 세 가지:

- **심박이 월 단위다.** 데이터가 월 파티션이라 어제와 오늘 화면이 같다. 매일 열 이유가 구조적으로 없다.
- **Pull 방식이다.** 자동 탐지 TOP 6·병목 점멸은 있지만 사용자가 열고 조작해야 나온다. CEO에게 필요한 것은 "열었더니 이미 골라져 있는 것"이다.
- **경쟁 축이 없다.** CEO 질문의 절반은 "경쟁 대비"(점유율·상대 인센티브·SAAR)인데 트윈은 자사 폐쇄계다.

## 3. 1-DAU 설계 — 무엇을 얹어야 매일 여는가

### ① 일 단위 심박 (Daily Heartbeat)
월 시뮬레이션 위에 **일 단위 선행지표 레이어**를 얹는다: 딜러 소매 일보, 리테일 인콰이어리/방문,
인센티브 소진율, 항만 통관·철도 위치, 딜러 주문 접수. 월 큐브(agg_kpi)는 그대로 두고
`daily_pulse` 피드만 추가 — 트윈의 몸은 월, 심박은 일.
**판정 화면: "월 계획 소화율" — 이달 계획 대비 D+n일 시점 정상 궤도인가** (철도 위 열차처럼).

### ② 첫 화면 = "오늘의 3가지" 브리핑 (Push)
자동 탐지를 푸시로 승격한다. 접속 즉시:
1. **어제와 달라진 것** (일 펄스 vs 전일·전주 패턴 이탈)
2. **예상 경로 이탈** (실적이 커밋된 시나리오 밴드를 벗어난 지점 — 팬차트가 이미 있으므로 판정만 추가)
3. **미래 경보** ("이대로면 D+45 사바나 케파 병목 → 4Q 영업이익 −$xxM" — capHit 탐지가 이미 있으므로 문장화만 필요)
각 항목 클릭 → 해당 씬 위치로 줌 + 근거 드릴. CEO의 목표 체류시간은 3분: "정상/비정상/소집" 판단.

### ③ 결정 스코어보드 (재방문 루프의 핵심)
시나리오 등록 → **커밋**(이것으로 간다) → 이후 매일 "실적이 커밋 밴드 안인가"를 첫 화면에서 추적.
CEO가 시킨 것의 성적표가 매일 갱신되는 것 — 이것이 가장 강한 재방문 동기다.
이탈 시: "West 인센티브 효과가 모델 예측의 60%만 실현 중 — 원인 후보: 경쟁사 리스 프로그램" 식으로 경보.

### ④ 회의 소집 워크플로 (트윈 = 회의의 공용 언어)
- 현재 뷰(커서 월·필터·포커스·시나리오 세트)를 **스냅샷 URL**로 고정 → "이 화면 보고 10시에 모여".
- 담당 임원은 **같은 뷰에서 이어서** 드릴(차종·트림·VIN·개선활동 원장)해 소명 — 데이터 정본이 하나라
  회의가 "숫자 맞추기"가 아니라 "판단"에서 시작된다. V7의 집계→VIN 3단 드릴이 이미 이 구조의 하반부다.
- 회의 결론 → Action Item으로 트윈에 저장 → ③의 스코어보드로 순환.

### ⑤ AI 워게이밍 — 시나리오 1~2개에서 10+개로
현재 엔진은 결정적이고 빠르다(레버 조합 1회 시뮬 ≈ 수 ms) — **N개 병렬 실행은 이미 기술적으로 공짜**다.
- CEO가 목표함수를 고른다: 이익 극대 / 점유율 방어 / CSI 하한 유지 (가중 조합).
- AI가 레버 조합 10~50개를 생성·실행·랭킹 → **파레토 프런트** 제시 (이익 vs 점유율 vs CSI 트레이드오프).
- 외부 충격 라이브러리(관세 ±, 금리, 유가, 경쟁사 인센티브 공세)를 곱해 **강건성 점수**: "10개 충격 중
  8개에서 계획 달성하는 조합"이 전쟁 시뮬레이션의 '가장 높은 확률의 시나리오'에 해당.
- CEO의 일은 조합 탐색이 아니라 **트레이드오프 선택**으로 바뀐다.

### ⑥ 이중 모드 — 요약형 CEO와 실무형 CEO
- **브리핑 모드** (기본): 오늘의 3가지 + 스코어보드 + KPI 4타일. 조작 없음.
- **오퍼레이터 모드**: 지금의 V7 전체 (레버 직접 조작·상세분석 필터·워게이밍 실행).
  포드형 CEO는 인센티브 $/대·모델별 DS까지 직접 만지므로 레버 해상도를 모델×지역 단위로 세분
  (현재는 전사 일괄 — `v7-strategy-scenarios.md`의 레버 5종을 매트릭스화).

| 갭 | 내용 | 소비처 |
|---|---|---|

| 일 단위 펄스 | 소매 일보·인콰이어리·인센 소진·물류 위치 | ①② |

| 충격 라이브러리 | 관세·금리·유가·경쟁 공세 파라미터화 | ⑤ 강건성 평가 |

## 5. 로드맵 접속 — 기존 4단계와의 결합

`twin-insight-review.md`의 1~4단계 중 **4단계(AI 브리핑)를 1-DAU를 위해 앞당겨야 한다.**
순서 제안: ②첫화면 브리핑(기존 탐지 재활용, 최소 공수) → ③커밋·스코어보드 → ⑤워게이밍(엔진 재활용)
→ ①일 펄스(데이터 신규) → ⑥레버 매트릭스. 경쟁 데이터(§4)는 ⑤와 병행 조달.

**한 줄 결론: 트윈의 몸(씬·드릴·시뮬 엔진)은 준비됐다. 매일 열게 만드는 것은 몸이 아니라
"오늘의 3가지 + 내 결정의 성적표" — 푸시와 추적 루프다.**
