# 디지털 트윈 비즈니스 케이스 — 가치 가설과 검증 계획

- **작성일**: 2026-08-28
- **목적**: 방향성 리뷰(§2-G)가 지적한 "ROI 정량 가설 부재"를 해소한다 — 경영 투자 승인과
  P2(실데이터) 이후 가치 검증의 기준 문서.
- **주의**: 아래 수치는 **가설**이다. 규모 가정은 BP(연 790,000대)·프로토타입 모델
  파라미터·업계 통상치에서 도출했고, 전부 P2 실데이터 캘리브레이션으로 갱신한다.
  각 가설에 측정 지표·검증 방법·판정 시점을 붙였다 — 검증 없는 가치 주장은 금지.

## 1. 가치 가설 — 레버별

### H1. 인센티브 효율 (전략 What-if · 워게이밍)
- **가설**: 차종×월 단위 탄력 기반 최적화로 동일 판매량 대비 인센티브 지출 **1~3% 절감**.
- **연 가치**: $12M ~ $36M (연 $1.2B 풀 기준).
- **지표**: 대당 인센티브(incunit) vs 소매량 — 시나리오 커밋 밴드 대비 실적.
- **검증**: 분기 1회, 트윈 권고안 적용 차종 vs 미적용 차종 diff-in-diff. 판정: P2+2분기.

### H2. 재고일수 최적화 (DoS Weight 주문 배분)
- **가설**: 지역·차종 배분 정밀화로 평균 DS **60→55일 (-5일)**, 파이프라인 자본 ~$430M 감소.
- **연 가치**: 금융비 6% 기준 **~$26M** (딜러 플로어플랜 + 법인 지원 분담) + 노후재고
  인센티브 회피(H1과 중복 계상 금지 — 별도 측정).
- **지표**: 월 DS, 90일+ 재고 비중, 지역 간 DS 편차.
- **검증**: 월 배분안의 트윈 권고 vs 실제 결정 기록(결정 스코어보드) 6개월 추적. 판정: P3.

### H3. 품질 선제 대응 (VoC·텔레매틱스→OTA 폐루프)
- **가설**: 신호 조기 탐지·OTA 선제 시정으로 보증비 **3~5% 절감** + 리콜 1건 조기화.
- **연 가치**: $6M ~ $10M (연 $0.2B 기준). 리콜 조기 대응 1건의 회피 비용은 별도(사건당 수십 $M).
- **지표**: 클레임/1k(발생→시정 소요일), OTA 적용 누계 vs 클레임 소멸 곡선 (프로토타입
  OTA-2606-LUM 사례: 8.5→0.4/1k).
- **검증**: 이슈별 pre/post 클레임률 — csi_actions 원장이 이미 이 구조를 가진다. 판정: P2+1분기.

### H4. 관리비 레버 (HVAC 등 시설 에너지)
- **가설**: 피크 설정온도·예냉 레버로 전력비 절감 — 기존 산출 **월 ~$10만 = 연 ~$1.2M**.
- **지표**: 건물×층 피크 kWh·전력비 — facility_energy 마트.
- **검증**: 레버 적용 전후 월 비교(기온 보정). 판정: 적용 즉시 (가장 빠른 검증 가능 가설 —
  1호 신뢰 확보용으로 우선 실행).

### H5. 마감·보고 공수 (월 재무 마감·VoC 분류 자동화)
- **가설**: 일 단위 가마감 + LLM VoC 분류로 마감 **영업일 +5 → +1**, 부문 보고 취합
  공수 **월 ~200시간 절감** (8사 리서치의 before/after 기준).
- **연 가치**: 직접 인건비 환산 ~$0.3M + **의사결정 리드타임 단축**(정성 — 아래 H6의 전제).
- **지표**: 마감 소요일, VoC 분류 지연(접수→분류), 브리핑 생성 시각.
- **검증**: 파이프라인 가동 전후 실측. 판정: P2.

### H6. 의사결정 품질 (워게이밍·결정 스코어보드)
- **가설**: 결정의 사전 시뮬레이션·사후 검증 체계화로 "번복·지연 결정" 감소 —
  정량화는 **결정 스코어보드 자체가 측정 도구** (커밋 밴드 이탈률, 결정→실행 리드타임).
- **검증**: 스코어보드 6개월 누적 후 이탈률 추세로 판정. 선행 조건: 시뮬레이션 신뢰
  (아래 §3 백테스트 공개).

**합계(중복 제거, 보수적 하단)**: 연 **$45M~** 수준의 검증 가능 가치 가설 vs 구축·운영
투자(P1~P4 추정치는 별도 산정 문서) — 단, **합계는 승인용 어림값일 뿐, 집행 판단은
가설별 검증 통과에 따른다.**

## 3. 시뮬레이션 신뢰 — 백테스트 공개 원칙

가치 가설 H1·H2·H6은 "시뮬레이션을 믿고 결정한다"를 전제한다. 따라서:
1. **캘리브레이션**: 탄력 파라미터(가격·인센티브·adstock)를 자사 32개월+ 실적으로 재추정 (P2).
2. **백테스트**: 홀드아웃 6개월 MAPE를 KPI별로 산출해 **화면에 상시 공개** (mlModel
   레지스트리의 quality_metric — 숨기지 않는다).
3. **게이팅**: MAPE가 기준(판매량 ±8%, 이익 ±12% — 가설)을 넘는 KPI는 시뮬레이션
   결과에 "저신뢰" 배지를 붙이고 결정 근거로 인용 금지.

  전까지 지원 불가 (데이터 수집 프로젝트로 등록).
- **일 단위 심박 미구현** — H5·채택 지표의 1-DAU 전환은 일 파티션 데이터(소매 일보·
  인센 소진율) 신설이 선행 조건 (P3).
- **딜러 경제 미커버** — 가격 개정·인센티브 결정의 딜러 수익성 영향은 반쪽 정보 (P2 백로그).
